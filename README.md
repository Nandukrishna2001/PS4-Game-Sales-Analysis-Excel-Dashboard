# 🎮 PS4 Game Sales Analytics Dashboard

An interactive **data analytics project** focused on analyzing PlayStation 4 game sales performance across genres, publishers, regions, and individual titles.

The project explores the commercial performance of PS4 games using sales data from **North America, Europe, Japan, Rest of World, and Global markets**. The analysis transforms raw game-sales data into meaningful insights about market trends, regional preferences, publisher contribution, genre performance, and the industry's top-performing titles.

# 🎯 Project Overview

The PS4 Game Sales Analytics project analyzes video-game sales performance to understand how different games, genres, publishers, and geographic markets contributed to the overall PS4 gaming market.

The analysis combines multiple dimensions of the dataset, including **game title, release year, genre, publisher, North American sales, European sales, Japanese sales, Rest of World sales, and Global sales**.

The project focuses not only on identifying the highest-selling games but also on understanding broader patterns such as genre performance, publisher concentration, regional differences, and changes in sales across release years.

---

# 🔍 Key Analysis Areas

## 🎮 Genre-wise Global Sales

The project compares global sales across different game genres to understand which categories generated the greatest overall commercial performance.

Genre-level analysis provides a broader view of consumer demand and allows global sales to be compared across categories such as Action, Sports, Shooter, Role-Playing, Racing, and other game genres.

This helps identify the genres that contributed most significantly to the overall PS4 game market.

---

## 🏢 Publisher Analysis

The dashboard examines publishers based on their contribution to the PS4 game market.

Publisher-level analysis includes the **number of games released and their contribution to overall sales**, helping identify publishers with a significant presence within the dataset.

The analysis also provides an understanding of how game releases are distributed across publishers and whether market activity is concentrated among a smaller group of publishers.

---

## 🌍 Regional Sales Comparison

The project compares game sales across four major geographic markets:

* North America
* Europe
* Japan
* Rest of World

Regional comparison makes it possible to understand differences in market performance and identify how the same genres or games perform across different geographic regions.

This provides a more detailed perspective than relying only on global sales figures.

---

## 🏆 Top-Selling Games

The dashboard identifies the **top-performing PS4 games based on global sales**.

The ranking provides a quick view of the titles that generated the highest commercial performance and allows their regional sales contributions to be compared.

This analysis helps connect individual game performance with broader genre, publisher, and regional trends.

---

## 📅 Sales Trend Analysis

The dataset also allows game sales to be examined across release years.

Year-based analysis helps explore how game releases and their commercial performance changed over time and provides a chronological view of the PS4 gaming market.

This can be used to identify periods with higher game-release activity and changes in overall market performance.

# 📈 Key Insights

The analysis provides several important perspectives on the PS4 game market:

* **Genre Performance:** Global sales vary considerably across game genres, allowing high-performing categories to be identified.
* **Publisher Contribution:** A significant share of game releases and sales can be compared across publishers to understand publisher presence.
* **Regional Preferences:** Sales patterns differ across North America, Europe, Japan, and Rest of World, highlighting geographic differences in game-market performance.
* **Top Titles:** A relatively small group of highly successful games contributes substantially to global sales.
* **Market Trends:** Release-year analysis provides a view of how game sales and releases evolved over the PS4 lifecycle.
* **Regional Contribution:** Individual games can be examined to understand how different regions contribute to their overall global sales.

# 🎯 Project Objective

The primary objective of this project is to analyze PS4 game sales data and understand the factors and patterns behind game-market performance.

Rather than looking only at total global sales, the project examines the data from multiple perspectives — **game, genre, publisher, region, and release year**.

This creates a more comprehensive view of the PS4 gaming market and demonstrates how raw sales data can be transformed into meaningful business and market insights.

---

# 💡 Analytical Value

The project demonstrates how sales data can be used to understand consumer behavior and market performance within the gaming industry.

By connecting **genre performance, publisher contribution, regional preferences, individual game success, and sales trends**, the analysis provides a structured view of the PS4 game market.

The project also demonstrates the importance of looking beyond a single KPI. Global sales provide an overall measure of success, while regional and genre-level analysis helps explain where and how that success was generated.
